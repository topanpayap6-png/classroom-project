# Classroom Studio เวอร์ชัน Firebase (ข้ามเครื่อง + ปลอดภัยจริง)

เวอร์ชันนี้เก็บข้อมูลบนเซิร์ฟเวอร์ Firebase (ของบัญชี Google คุณเอง) ทำให้
- ครูหลายคนใช้ข้อมูลชุดเดียวกันจากหลายเครื่อง
- **เซิร์ฟเวอร์เป็นผู้บังคับสิทธิ์**: ครูเข้าถึงได้เฉพาะห้องที่ได้รับมอบหมาย
- นักเรียนมีบัญชีของตัวเอง (สแกน QR + PIN 6 หลัก) และทำได้เฉพาะที่ครูอนุญาตในแต่ละห้อง: **ดูงานที่สั่ง / ส่งงาน / ดูดาวและคะแนน**

> ⚠️ ผู้จัดทำ (Claude) ทดสอบหน้าเว็บในเบราว์เซอร์จริงกับ "โหมดทดลอง" แล้ว แต่ **ไม่ได้ทดสอบกับ Firebase จริง** (ไม่มีอินเทอร์เน็ตในสภาพแวดล้อมที่สร้าง) กฎความปลอดภัย (`firestore.rules`, `storage.rules`) ตรวจด้วยการอ่านทบทวนเท่านั้น
> จึงขอให้ทำ "รายการตรวจสอบหลังติดตั้ง" ด้านล่างก่อนใส่ข้อมูลนักเรียนจริง

## ไฟล์ในแพ็ก

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html` | ตัวแอป (ไฟล์เดียว) แก้ค่า `FIREBASE_CONFIG` ใกล้ต้นไฟล์ |
| `firestore.rules` | กฎความปลอดภัยฐานข้อมูล **ต้องแก้ `setupCode()` ก่อนใช้** |
| `storage.rules` | กฎความปลอดภัยไฟล์ |
| `firestore.indexes.json` | ดัชนีที่หน้านักเรียนต้องใช้ |
| `firebase.json` | ตั้งค่าการ deploy |

## ลองก่อนติดตั้ง (โหมดทดลอง)
เปิด `public/index.html` ด้วย Chrome โดยยังไม่แก้อะไร จะเข้า "โหมดทดลอง" (รหัสตั้งค่า `DEMO`) ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น และไฟล์ที่แนบจะหายเมื่อรีเฟรช ใช้ดูหน้าตาและลองใช้งานเท่านั้น

## ค่าใช้จ่ายและเงื่อนไขที่ควรรู้ก่อน
- Authentication, Firestore, Hosting: มีโควตาฟรี (แพ็กเกจ Spark) เพียงพอสำหรับห้องเรียนไม่กี่ห้อง
- **Cloud Storage (ไฟล์แนบ/ไฟล์งาน):** โปรเจกต์ใหม่มักถูกกำหนดให้ใช้แพ็กเกจ **Blaze (จ่ายตามใช้ ต้องผูกบัตร)** แม้โควตาฟรีจะครอบคลุมการใช้งานเล็กๆ ให้ตรวจในหน้า Storage ของคอนโซลก่อน ถ้าไม่ต้องการผูกบัตร ระบบส่วนอื่นยังใช้ได้ แต่แนบไฟล์/ส่งไฟล์ไม่ได้ (ส่งข้อความได้)
- **ข้อมูลส่วนบุคคลของเด็ก:** ชื่อ รูปงาน และคะแนนของนักเรียนจะถูกเก็บบนเซิร์ฟเวอร์ Google ภายใต้บัญชีของคุณ ควรได้รับความยินยอมจากผู้ปกครองและเป็นไปตามนโยบายโรงเรียน/PDPA

## ขั้นตอนติดตั้ง

### 1) สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com แล้วกด **Add project** (ตั้งชื่อ เช่น `classroom-studio`)
2. **Build > Authentication > Get started > Sign-in method** เปิด **Email/Password**
3. **Build > Firestore Database > Create database** เลือกโหมด **production** และตำแหน่ง เช่น `asia-southeast1` (สิงคโปร์)
4. **Build > Storage > Get started** (อาจต้องอัปเกรดเป็น Blaze ตามหัวข้อด้านบน)
5. **Project settings (ไอคอนฟันเฟือง) > Your apps > ไอคอน `</>` (Web)** ลงทะเบียนแอป แล้วคัดลอกค่า `firebaseConfig`

### 2) ใส่ค่าตั้งค่าในไฟล์
- เปิด `public/index.html` ค้นหา `FIREBASE_CONFIG` แล้ววางค่าที่คัดลอกมาแทนค่า `YOUR_...`
- เปิด `firestore.rules` แก้บรรทัด `function setupCode() { return 'CHANGE-THIS-SETUP-CODE'; }` เป็น **รหัสลับของคุณเอง** (ใช้ครั้งเดียวตอนสร้างผู้ดูแลคนแรก กันคนแปลกหน้าสมัครเป็นผู้ดูแลก่อนคุณ)

### 3) Deploy
ต้องติดตั้ง Node.js ก่อน (https://nodejs.org) แล้วเปิด Terminal ในโฟลเดอร์นี้:
```
npm install -g firebase-tools
firebase login
firebase use --add          # เลือกโปรเจกต์ที่สร้างไว้
firebase deploy
```
- ตอน deploy กฎของ Storage ระบบอาจถามขอสิทธิ์ให้ Storage อ่าน Firestore ข้ามบริการ ให้ตอบ **ยืนยัน (Y)** (กฎไฟล์ต้องอ่านบทบาทผู้ใช้จาก Firestore)
- เสร็จแล้วจะได้ลิงก์ `https://<โปรเจกต์>.web.app` นี่คือลิงก์เว็บของคุณ
- **ห้ามเปิดไฟล์ด้วยการดับเบิลคลิก (file://)** เมื่อใช้ Firebase จริง ให้เปิดผ่านลิงก์ที่ deploy แล้ว (https)

### 4) ใช้งานครั้งแรก
1. เปิดลิงก์ จะเจอหน้า **ตั้งค่าครั้งแรก** ใส่รหัสตั้งค่าที่ตั้งใน `firestore.rules` พร้อมชื่อ อีเมล รหัสผ่านผู้ดูแล
2. สร้างห้องแรก
3. เมนู **จัดการครู** เพิ่มครูคนอื่น ติ๊กห้องที่แต่ละคนสอน (ครูล็อกอินด้วยอีเมล+รหัสผ่านที่คุณตั้งให้ และเปลี่ยนรหัสผ่านทางอีเมลได้)
4. เมนู **จัดการห้อง/วิชา** เพิ่มห้อง วิชา และตั้ง **สิทธิ์ของนักเรียนในห้อง** (ดูงาน / ส่งงาน / ดูคะแนน)
5. เพิ่มนักเรียน ระบบสร้างบัญชีนักเรียนให้อัตโนมัติ พร้อมรหัสนักเรียนและ PIN 6 หลัก (ดู PIN ได้ในหน้านักเรียน หรือหน้า "บัตร QR") แล้วพิมพ์/แจกบัตร QR
6. นักเรียนสแกน QR (เปิดลิงก์เว็บพร้อมรหัสนักเรียน) แล้วใส่ PIN

## การทำงานของสิทธิ์นักเรียน (บังคับที่เซิร์ฟเวอร์)

| ที่ครูติ๊กไว้ | นักเรียนทำได้ |
|---|---|
| ดูงานอย่างเดียว | เห็นรายการงานที่ถูกสั่งให้ตัวเอง คำอธิบาย กำหนดส่ง ไฟล์ที่ครูแนบ |
| ส่งงาน | เห็นงาน + ส่งไฟล์/ข้อความได้ (ส่งใหม่ทับได้) จนถึงสิ้นวันกำหนดส่ง (เซิร์ฟเวอร์ตรวจเวลา) |
| ดูดาวและคะแนน | เห็นดาว กิจกรรม (นม/แปรงฟัน/ข้าว) และคะแนนของตัวเอง |
| ปิดทั้งหมด | ล็อกอินได้ แต่ไม่เห็นข้อมูลใดๆ |

นักเรียนเห็นเฉพาะข้อมูลของตัวเองเสมอ (ไม่เห็นเพื่อน ไม่เห็นห้องอื่น)

## รายการตรวจสอบหลังติดตั้ง (ทำก่อนใส่ข้อมูลจริง)
ใช้บัญชีทดลอง 2 ห้อง 2 ครู 1 นักเรียน แล้วตรวจ:
1. ครู B ล็อกอินแล้ว **ไม่เห็นห้อง A และนักเรียนของห้อง A** ✔
2. ใน Firebase Console > Firestore > แท็บ **Rules > Rules Playground** จำลองคำขอ `get /students/<รหัสนักเรียนห้อง A>` ในฐานะผู้ใช้ครู B → ต้องได้ **Denied**
3. ตั้งสิทธิ์ห้อง = "ดูงานอย่างเดียว" แล้วล็อกอินเป็นนักเรียน → ไม่มีปุ่มส่งงาน และไม่เห็นดาว/คะแนน ✔ ใน Rules Playground จำลอง `create /submissions/<รหัสงาน>_<รหัสนักเรียน>` ในฐานะนักเรียนนั้น → ต้อง **Denied**
4. นักเรียนล็อกอินด้วย PIN ผิดหลายครั้ง → ระบบหน่วงเวลา (`too-many-requests`) ✔
5. คนที่ไม่ได้ล็อกอินเปิดคอนโซลเบราว์เซอร์แล้วอ่านข้อมูล → ต้องไม่ได้ข้อมูล (permission-denied)
ถ้าข้อใดไม่ผ่าน **อย่าใช้กับข้อมูลจริง** และแจ้งผลกลับมาเพื่อแก้กฎ

## ปัญหาที่พบบ่อย
- **`permission-denied` ทุกอย่าง:** ยังไม่ได้ `firebase deploy` กฎ หรือยังไม่ได้ทำขั้นตอนตั้งค่าครั้งแรก
- **หน้านักเรียนขึ้นข้อความเรื่อง index:** Firestore จะแสดงลิงก์สร้างดัชนีในคอนโซลเบราว์เซอร์ กดลิงก์แล้วรอสร้างเสร็จ (ปกติ `firebase deploy` สร้างให้แล้ว)
- **สร้างบัญชีนักเรียนไม่ได้ (`invalid-email`):** แอปใช้อีเมลภายในรูปแบบ `...@students.classroom.invalid` ถ้า Firebase ไม่รับ ให้แก้ข้อความ `students.classroom.invalid` ใน `index.html` เป็นโดเมนอื่น เช่น `students.example.com` (ต้องแก้ก่อนสร้างนักเรียน)
- **อัปโหลดไฟล์ไม่ได้:** Storage ยังไม่เปิด/ยังเป็นแพ็กเกจที่ไม่รองรับ หรือยังไม่ได้ deploy `storage.rules` และอนุญาตให้ Storage อ่าน Firestore
- **เข้าจากโดเมนอื่นไม่ได้:** เพิ่มโดเมนใน Authentication > Settings > Authorized domains

## ข้อจำกัดที่ควรรู้
- ครูสองคนแก้ข้อมูลเดียวกันพร้อมกัน (เช่น ดาวของนักเรียนคนเดียวกัน) ใช้หลักใครบันทึกทีหลังชนะ
- ลบครู = ถอนสิทธิ์ (บัญชีอีเมลยังอยู่ใน Authentication ลบเองได้ในคอนโซล) ลบนักเรียน = ถอนสิทธิ์และลบ PIN/รหัสนักเรียนที่เกี่ยวข้อง
- PIN นักเรียนเก็บเป็นข้อความธรรมดาในชุดข้อมูลที่อ่านได้เฉพาะครูของห้อง (ครูต้องใช้บอกนักเรียน) เปลี่ยน PIN ได้ในหน้านักเรียน (บัตร QR เดิมใช้ต่อได้)
- กำหนดส่งนับถึง 23:59 ตามเวลาในเครื่องของครูที่สั่งงาน
- การส่งขึ้น Google Sheets/Form และการจัดกลุ่ม สุ่มชื่อ ฯลฯ ทำงานเหมือนเวอร์ชันเดิม (ไม่ซิงก์ข้ามเครื่อง สำหรับค่าตั้ง Google Form)
- ใช้ Tailwind จาก CDN (ต้องมีอินเทอร์เน็ตเพื่อให้หน้าตาครบ)
